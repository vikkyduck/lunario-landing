# Дизайнерский бриф — лендинг Лунарио

**Источник дизайна:** «Дизайн-система Лунарио.html» v1.0 (кросс-форматная ДС, Figma Make).
Дизайн НЕ придумываем — реализуем брендбук 1:1. Расхождение с «рекомендуемой палитрой»
из ТЗ (сине-бирюзовая) решено в пользу брендбука — прямое указание Виктории.

## Впечатление

«Эзотерика как мудрая опора — не мистика, не магия, а спокойный собеседник в жизни
современной женщины». Архетип: Мудрец + Заботливый. Wellness/AI-продукт с мягкой
символикой, не «магазин эзотерики».

- Подходит: тёплый, спокойный, личный.
- НЕ: корпоративный, НЕ кричащий, НЕ мистически-тёмный.

## Палитра (из брендбука)

| Роль | Цвет |
|---|---|
| Индиго ночи — основной текст, тёмные блоки | `#1E1B3A` (+ `#2D2A55`, `#3A3550`) |
| Лаванда — акценты, разделители, иконки | `#9B8FC0` (+ светлая `#C8C0DF`) |
| Лаванда бледная — фон карточек, секций | `#EDE8F5` |
| Золото — CTA, логотип, premium-маркеры | `#D4A853` (+ `#F0E4C0`, тёмное `#C4974A`) |
| Терракота — живость, срочность (дозированно) | `#C4714E` |
| Шалфей — баланс, подтверждение | `#8BA888` |
| Крем — фон сайта | `#F4EFE6` |

Режим лендинга — **светлый**: «Сайт · светлая страница — фоновый крем, индиго для текста»
(прямо из брендбука). Тёмный индиго — для hero-градиента, мокапа приложения и контрастных
блоков. Градиент — hero-секции и обложки.

## Типографика

Брендбук: Fraunces (display serif, humanist) / DM Sans (body) / DM Mono (метки).
Кириллических начертаний у них нет → **утверждённые ранее замены** (решение по Лунарио
от июля 2026): **Lora** (display) / **Golos Text** (body) / **JetBrains Mono** (метки).
Шрифты самостоятельно хостим на VDS (не Google-CDN) — быстрее и без передачи данных третьим лицам.

## Графика и иллюстрации

- Тонкая контурная линия 1–1.5px, небесная геометрия, фазы луны, звёздное поле-орнамент.
- Золотые и лавандовые акценты на тёмном; абстракция без фигур людей.
- Мокап телефона на первом экране — вёрстка UI-карточек из брендбука
  («Карта дня», «Луна в Тельце», подсказка дня), не стоковые скриншоты.

## Визуальные запреты (брендбук + ТЗ)

Готические шрифты, черепа, хрустальные шары, дым/туман, звёздная пыль и блёстки,
чёрный фон на всём сайте, неоновый фиолетовый, тяжёлые золотые рамки, фото «гадалок»,
мелкий текст, длинные абзацы, избыточная анимация.

## Плотность и мобильные приоритеты

- Mobile-first (по ТЗ мобильная версия проектируется первой), CTA виден без прокрутки.
- Крупный шрифт, высокий контраст, много воздуха — «аудитория устала от мелкого текста».
- Анимации — минимальные и мягкие (появление блоков, ничего непрерывно движущегося).

## Тон

Тёплый, спокойный, на «вы», без давления страхом. Ошибка формы в голосе бренда:
«Что-то пошло не так. Попробуем ещё раз — Луна видела и похуже».
