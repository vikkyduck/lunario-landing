# Лунарио — лендинг lunario.online

Витрина приложения «Лунарио» с А/Б-тестом заголовков и приёмом заявок.
Живёт на **https://lunario.online**, приложение — в соседнем репозитории
[lunario-app](https://github.com/vikkyduck/lunario-app).

## Как устроено

- `site/` — статика: страница-витрина (`index.html` с плейсхолдерами
  `{{VARIANT}}`/`{{H1}}`), документы (политика, согласие), прототип.
- `backend/server.mjs` — Node ≥ 22.5 без зависимостей, `node:sqlite`:
  выдаёт вариант A/B строгим чередованием (закрепляется cookie на 90 дней),
  принимает заявки (honeypot + rate limit + фиксация согласия), шлёт
  уведомления в Telegram без персональных данных, админка `/admin`
  с воронкой по вариантам и выгрузкой CSV.
- `docs/` — брифы, смысловая структура, юридическая карта (152-ФЗ),
  архитектура: весь путь от задачи до запуска.
- `deploy/` — nginx-конфиг и инструкция первичной установки.
- `tools/` — служебное (обход VPN-туннеля для доступа к серверу).

## Запуск локально

```bash
PORT=5030 DB_FILE=./data/lunario.db ADMIN_USER=admin ADMIN_PASS=test node backend/server.mjs
# http://localhost:5030 — варианты чередуются; /?ab=A и /?ab=B — предпросмотр
```

Секреты (токен бота, пароль админки, номер Метрики) задаются в `.env`
на сервере — см. `backend/.env.example`. В коде секретов нет.

## Деплой

`./deploy.sh` — rsync статики и бэкенда на сервер + перезапуск systemd.
